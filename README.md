# FreeRTOS Learning Repository

This repository documents my journey of learning FreeRTOS on ESP32 through small, focused examples.

## Topics Covered

- Task Creation
- Task States
- Scheduling
- Priorities
- Context Switching
- Queues
- Semaphores
- Mutexes
- Event Groups

## Structure

```text
01_Task_Creation
02_Task_Delay
03_Task_Priorities
04_Queues
05_Semaphores
```

## Goal

The goal of this repository is to understand RTOS concepts from first principles and gradually build practical embedded and IoT applications using ESP32 and FreeRTOS.

## Platform

- ESP32
- Arduino IDE
- FreeRTOS
